# DonorLog

**DonorLog** — современный мобильный клиент и сервисное приложение для доноров крови и ее компонентов. Разработано в рамках курса «Программирование для мобильных устройств» (Московский Политех).

## Структура репозитория

- `donorlog-android/` — клиентское Android-приложение (Java, Material Design 3, Room, Canvas Widgets, Notifications, SQLite/Room, REST API Client).
- `donorlog-backend/` — серверная часть (Java 17, Spring Boot 3, Spring Data JPA, H2/PostgreSQL, REST API, Swagger/OpenAPI).

## Основные функциональные возможности

- **Медицинский калькулятор интервалов**: автоматический расчет сроков до следующей кроводачи согласно приказам Минздрава РФ с учетом пола донора и истории донаций (цельная кровь, плазма, тромбоциты, эритроциты).
- **Траектория звания «Почетный донор»**:
  - Федеральная программа: 4 законодательные схемы по 125-ФЗ с выбором оптимального пути;
  - Региональная программа: траектория «Почетный донор Москвы» (Закон г. Москвы № 70).
- **Оперативный донорский светофор**: отображение потребности станций переливания крови по группам и резус-факторам (онлайн-мониторинг + автономный режим).
- **Аналитика показателей здоровья**: мониторинг динамики гемоглобина, артериального давления, пульса и оценка вклада в спасение жизней.
- **Интерактивные виджеты рабочего стола (App Widgets 4×2)**:
  - Статус готовности и счетчик дней;
  - Графическая круговая диаграмма прогресса Почетного донора (отрисовка Canvas);
  - Светофор станций переливания крови;
  - Витальные биомаркеры (гемоглобин, давление, пульс).
- **Калькулятор медицинских отводов**: справочник противопоказаний и расчет даты снятия временных медотводов.
- **Памятка донорской диеты**: строгие правила подготовки организма за 48 и 24 часа до сдачи.
- **Уведомления**: оповещения о наступлении окна готовности и напоминания накануне донации.

## Требования к окружению

- Android Studio Ladybug / Koala или новее
- Android SDK 34 / 35 (minSdkVersion: 26, targetSdkVersion: 34)
- JDK 17+
- Gradle 8.x

## Быстрый запуск (Одновременно бэкенд и мобильное приложение)

В корне репозитория предусмотрены готовые скрипты автоматического развертывания полного стека:
* **PowerShell:**
  ```powershell
  .\run_all.ps1
  ```
* **Командная строка / Двойной клик в проводнике:**
  ```cmd
  run_all.bat
  ```

Скрипт автоматически:
1. Запускает серверный Spring Boot бэкенд на порту `8080` в отдельном информационном окне;
2. Проверяет наличие эмулятора/устройства, при необходимости запускает доступный AVD и ожидает готовности;
3. Настраивает проброс портов `adb reverse tcp:8080 tcp:8080`;
4. Собирает и устанавливает актуальную версию Android-приложения (`installDebug`);
5. Открывает главный экран приложения на устройстве.

## Раздельный запуск и сборка

### Бэкенд
```bash
cd donorlog-backend
./gradlew bootRun
```
Сервер будет доступен по адресу `http://localhost:8080`.

### Android-клиент
Откройте директорию `donorlog-android` в Android Studio или выполните:
```bash
cd donorlog-android
./gradlew assembleDebug
```
